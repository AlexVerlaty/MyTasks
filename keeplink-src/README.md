# MyTasks · вход в Keep

Крошечное Android-приложение с одной задачей: помочь подключить Google Keep к боту
**MyTasks** прямо с телефона, без компьютера и без «инструментов разработчика».

Форк [`Villoh/goopdl-auth`](https://github.com/Villoh/goopdl-auth) (MIT). Логика обмена
токена не менялась; переименовано, переведено на русский и указывает на бота MyTasks.

Что именно отличается от оригинала — чтобы это можно было проверить, а не принять на веру:

- пакет `com.goopdl.auth` → `com.mytasks.keeplink`, тексты на русском, ссылки на бота;
- иконка: маскот goopdl-auth заменён на иконку MyTasks — ту же, что у бота и на сайте;
- релиз собирается с R8 (`isMinifyEnabled`, `isShrinkResources`) и с набором локалей
  `ru`, `en`: APK 5,8 МБ → 0,8 МБ;
- картинка для первого экрана вынесена в отдельный `drawable`, потому что
  `painterResource(@mipmap/ic_launcher)` на Android 8+ упирается в XML адаптивной иконки
  и роняет приложение на старте;
- `lint { checkReleaseBuilds = false }` — обход бага записи отчёта на сборочной машине.

Сетевой код (`EMBEDDED_SETUP_URL`, `AUTH_URL`, `fetchAasToken`, `pollForCredentials`) не
тронут: это тот же протокол, что в оригинале.

`.github/workflows/release.yml` достался от оригинала и срабатывает только на тег `v*`;
здесь он ничего не собирает — сборка была локальной.

## Что оно делает

1. Открывает страницу входа Google (`accounts.google.com/EmbeddedSetup`) внутри себя.
2. Ты входишь в свой аккаунт — пароль вводишь только на странице Google.
3. Приложение забирает из своей же сессии одноразовую строку `oauth_token` и меняет её у
   Google на постоянный ключ (`aas_et/…`).
4. Показывает этот ключ с кнопкой «Скопировать». Ты отправляешь его боту MyTasks в личный
   чат — бот подключает Keep и сразу стирает сообщение.

После этого приложение можно удалить: ключ уже у бота, приложение больше не нужно.

## Почему это безопасно ровно настолько, насколько сказано

- **Две сетевые точки, обе Google** и никаких других:
  `accounts.google.com/EmbeddedSetup` (вход) и `android.clients.google.com/auth` (обмен).
  Проверить — `MainActivity.kt`, константы `EMBEDDED_SETUP_URL` и `AUTH_URL`.
- **Ключ никуда не отправляется** приложением: он только показывается на экране и кладётся
  в буфер обмена по твоему нажатию. На диск не пишется, в лог не пишется, аналитики нет.
- **Одно разрешение — `INTERNET`.** Ни контактов, ни файлов, ни фоновой работы.
- Весь код — один файл, ~300 строк. Его можно прочитать целиком.
- **Около 1 МБ.** Релиз собирается с R8 (`isMinifyEnabled`, `isShrinkResources`): без него
  APK весил 5,8 МБ, из которых почти всё — Jetpack Compose, приехавший целиком ради экрана
  из кнопки и WebView. Чем меньше кода внутри, тем правдивее утверждение, что приложение
  маленькое.

Честно про границу: ключ `aas_et/…` **постоянный и открывает весь Google-аккаунт**. Он
нужен, потому что у Google Keep нет обычного OAuth для личных аккаунтов. Отправляй эту
строку **только** боту MyTasks и никому больше.

## Установка

Приложения нет в Play Store — оно ставится файлом (`.apk`):

1. Скачай `mytasks-keeplink.apk`.
2. Открой его. Android спросит разрешение ставить из этого источника — разреши только для
   браузера/файлов, которым скачал.
3. Открой приложение, нажми «Войти в Google», дальше по шагам на экране.

Работает на Android. **На iPhone не работает** — Safari не отдаёт приложениям нужную куку;
для iPhone способа с телефона нет, только компьютер.

## Сборка из исходников

Нужен JDK 17 и Android SDK.

```
KEYSTORE_FILE=… KEYSTORE_PASSWORD=… KEY_ALIAS=… KEY_PASSWORD=… \
  ./gradlew assembleRelease
```

APK окажется в `app/build/outputs/apk/release/`.
